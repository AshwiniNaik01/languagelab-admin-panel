middleware.js

middleware.js Route Protection
What this file does: This is a Next.js Edge Middleware file. It runs before every page request on the server. Its only job is to check whether the user has a login token. If they don't, it redirects them to the login page.
LineCodeExplanation
1import { NextResponse } from "next/server"; IMPORT Brings in NextResponse from Next.js. This is the tool used to send responses — either "continue to the page" or "redirect to login".
3–7const PROTECTED = [...] CONFIG Defines an array of route prefixes that require login. Any URL starting with one of these strings is "protected". /editor, /institutes, /students, /editors, /licenses, /courses, /sessions, /analytics, /content, /profile.
9export function middleware(request) { EXPORT Declares and exports the middleware function. Next.js automatically calls this function for every matching request before serving the page.
10const { pathname } = request.nextUrl; LOGIC Extracts just the path part of the URL (e.g. /institutes/new) from the incoming request object.
11const isProtected = PROTECTED.some((p) => pathname.startsWith(p)); LOGIC Checks if the current URL starts with ANY of the protected prefixes. .some() returns true as soon as one match is found. If it's not protected, skip everything.
12if (!isProtected) return NextResponse.next(); LOGIC If the route is not protected (e.g. the login page itself), immediately let the request through. NextResponse.next() means "proceed normally".
14–16const token = request.cookies.get("token")?.value || request.cookies.get("editor_token")?.value; LOGIC Reads cookies from the request. First tries to find a token cookie (admin), then falls back to editor_token. The ?. (optional chaining) prevents crashes if the cookie doesn't exist.
18–20if (!token) { return NextResponse.redirect(...) } LOGIC If no token is found, redirect the user to /admin-login. new URL("/admin-login", request.url) builds the full redirect URL. The user never sees the protected page.
21return NextResponse.next(); LOGIC If a token exists, let the request through normally. The user can see the page.
24–31export const config = { matcher: [...] } CONFIG Tells Next.js which URLs this middleware should run on. Each entry uses the :path* wildcard to match the route and all sub-routes. Without this, the middleware would run on every single request including images and API calls.

Error Boundary

app/components/ErrorBoundary.jsx Error Handling
What this file does: A React class component that catches JavaScript errors inside editor pages and shows a friendly "Something went wrong" message with a retry button, instead of crashing the whole app.
LineCodeExplanation
1"use client"; DIRECTIVE Error boundaries must be client components in Next.js App Router.
3import { Component } from "react"; IMPORT Imports React's base class. Error boundaries must be class components — they cannot be written as function components because they need lifecycle methods like getDerivedStateFromError.
5export default class ErrorBoundary extends Component { EXPORT Declares a class component. extends Component gives it React lifecycle methods.
6–9constructor(props) { super(props); this.state = { hasError: false, error: null }; } LOGIC The constructor runs when the component is created. super(props) is required to properly initialize the React Component class. this.state stores two things: whether an error occurred, and what the error is.
11–13static getDerivedStateFromError(error) { return { hasError: true, error }; } LOGIC A React lifecycle method that runs automatically when a child component throws an error. It updates the state to record that an error happened. static means it belongs to the class, not an instance.
15–17componentDidCatch(error, info) { console.error("ErrorBoundary caught:", error, info); } LOGIC Another lifecycle method that fires after an error is caught. Used for logging. info contains the component stack trace showing where the error occurred.
19–38render() { if (this.state.hasError) { return (<error UI>) } return this.props.children; } RENDER If error: Shows a warning box with the error message and a "Try Again" button.
"Try Again" button: Calls this.setState({ hasError: false, error: null }) which resets state and tries to re-render the children.
If no error: Renders children normally — completely transparent.
